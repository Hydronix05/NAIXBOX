# Changelog

Notable changes to NAIXBOX are documented here.

## [0.1.0] - Initial repository snapshot

- Added the first single-file browser prototype in `index.html`.
- Added seeded procedural terrain with chunk loading.
- Added first-person movement, basic physics, and block interaction.
- Added a hotbar, inventory interface, and touch controls.
- Added loading progress and runtime error reporting.

This entry records the code snapshot currently committed to the repository; it is not a claim of a public release.
