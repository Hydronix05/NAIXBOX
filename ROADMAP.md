# NAIXBOX Roadmap

This is a planning document, not a list of completed features. Priorities may change as the prototype is tested.

## Current foundation

- [x] Single-page browser prototype
- [x] Seeded terrain generation
- [x] Chunk-based rendering
- [x] Basic first-person movement and collision
- [x] Block breaking and placement
- [x] Hotbar and inventory UI
- [x] Desktop and touch input paths

## Near-term priorities

- [ ] Test and tune performance on low-end devices
- [ ] Finish the Settings screen and connect it to runtime settings
- [ ] Review touch controls across different screen sizes
- [ ] Add a reliable world save/load design
- [ ] Improve error messages and debugging information
- [ ] Split the single HTML file into maintainable modules when the codebase is ready

## Later possibilities

- [ ] More block types and world-generation variety
- [ ] Better block visuals and optional lightweight textures
- [ ] Audio and additional gameplay feedback
- [ ] More configurable world and player settings

Items in the later section are ideas only. They are not implemented or promised features.
