# Controls

## Desktop

| Action | Input |
|---|---|
| Move forward | W or Up Arrow |
| Move backward | S or Down Arrow |
| Move left | A or Left Arrow |
| Move right | D or Right Arrow |
| Look around | Click the game view, then move the mouse |
| Jump | Space |
| Break targeted block | H or left mouse button |
| Place selected block | E or right mouse button |
| Open / close inventory | Tab or I |
| Select hotbar slots 1–9 | Number keys 1–9 |
| Select hotbar slot 10 | 0 |

Clicking the game view requests pointer lock so mouse movement can control the camera. Escape releases pointer lock.

## Touch devices

- Use the left-side virtual joystick to move.
- Drag on the right side of the screen to look around.
- Use **JUMP**, **BREAK**, and **PLACE** for actions.
- Tap a hotbar slot to select it.
- Use the inventory control to open the inventory.

Touch controls are shown when the app detects a touch-oriented device. Exact placement can vary with screen size.

## Inventory

The hotbar contains ten slots. The inventory panel contains 36 additional slots. Inside the inventory, tap or click a filled slot to pick up its block, then select another slot to place it there.
